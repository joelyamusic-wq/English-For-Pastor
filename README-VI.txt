ENGLISH FOR PASTORS — HƯỚNG DẪN ĐƯA WEBSITE LÊN MẠNG MIỄN PHÍ

Trong gói này có:
- index.html: website học 30 ngày
- manifest.webmanifest và icon.svg: thông tin để thêm vào màn hình chính như app
- sw.js: bộ nhớ đệm để website có thể mở lại khi mạng yếu/sau lần tải đầu

CÁCH ĐƯA LÊN MẠNG BẰNG GITHUB PAGES (MIỄN PHÍ)
1. Trên máy tính, mở https://github.com và đăng nhập hoặc tạo tài khoản.
2. Bấm dấu + ở góc trên, chọn New repository. Đặt tên: english-for-pastors. Chọn Public, rồi tạo repository.
3. Trong repository, chọn Add file > Upload files. Giải nén gói ZIP này trước, rồi kéo 4 tệp index.html, manifest.webmanifest, sw.js và icon.svg vào vùng tải lên.
4. Bấm Commit changes để lưu các tệp.
5. Mở Settings > Pages. Trong Build and deployment, chọn Deploy from a branch; chọn branch main và folder /(root), rồi Save.
6. Chờ vài phút. Trang GitHub Pages sẽ hiện địa chỉ dạng https://TEN-TAI-KHOAN.github.io/english-for-pastors/ . Địa chỉ thật phụ thuộc tên tài khoản GitHub của thầy; không thể đoán trước.
7. Mở địa chỉ đó bằng Chrome trên điện thoại. Chọn menu ⋮ > Add to Home screen (Thêm vào màn hình chính) hoặc Install app nếu tùy chọn xuất hiện.

LƯU Ý
- Đây là website tĩnh miễn phí; chưa có tài khoản học viên hoặc đồng bộ tiến độ giữa các thiết bị. Tiến độ hiện lưu trong trình duyệt của từng thiết bị.
- Không cần mua tên miền. Có thể mua tên miền riêng sau này nếu muốn.
- GitHub Pages cần repository Public ở gói miễn phí. Không tải lên dữ liệu cá nhân hoặc bí mật.
